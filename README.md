# EMBERFALL — Agent Handoff Repository

This private repository is being initialized as the shared engineering handoff for **EMBERFALL**, the portrait-first Android roguelike puzzle deckbuilder.

The first substantive handoff is maintained on:

- Branch: `handoff/emberfall-coding-agent-v1.0`
- Entry point: `README.md` on that branch
- Roadmap: `engineering/CODING_AGENT_ROADMAP.md`
- Principal coding-agent brief: `engineering/MASTER_CODING_AGENT_PROMPT.md`
- Work breakdown: `engineering/IMPLEMENTATION_WBS.json` and `.csv`
- Maestro v0.3 workflow packets and helpers: `maestro/`

The `main` branch is only the repository bootstrap. Product and implementation work must use the dedicated handoff branch until a human selects the long-term branching policy.

**Access:** this repository is private. Add every human or service identity that must collaborate through GitHub repository access controls.

**Safety:** the handoff documents are plans and acceptance contracts, not evidence that game code has already been implemented or independently reviewed.
